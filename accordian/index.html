🧠 20 Must-Know Web Dev Questions

HTML (HyperText Markup Language) is the foundation of web pages, used to structure content.

CSS (Cascading Style Sheets) styles the HTML content—colors, layout, fonts, and responsiveness.

JavaScript adds interactivity to web pages like form validation, animations, and API calls.

An id is unique and used once per page; a class can be reused across multiple elements.

Responsive design makes websites adapt to different screen sizes using CSS and media queries.

A div is a block-level container used to group HTML elements for styling or scripting.

Semantic tags like <header>, <article>, and <footer> give meaning to the content.

The Document Object Model (DOM) is a programming interface for HTML that allows scripts to change the content and structure.

An API (Application Programming Interface) lets software talk to other software or services.

localStorage allows you to store data in the browser that persists even after page reloads.

var is function-scoped, let and const are block-scoped. const cannot be reassigned.

A media query applies different styles depending on screen size or device characteristics.

A pseudo-class like :hover or :nth-child targets elements in specific states.

Flexbox is a layout model in CSS that allows responsive alignment of elements in a container.

The box model consists of content, padding, border, and margin used to structure elements.

z-index controls the stacking order of overlapping HTML elements.

An event listener watches for user actions like clicks, scrolls, or key presses.

A CDN (Content Delivery Network) distributes your content across multiple servers for faster delivery.

Version control systems like Git track and manage changes in code over time.

Accessibility means designing websites usable by people with disabilities using tools like screen readers.
